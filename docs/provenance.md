# Provenance

The project scaffold was generated with [Spring Initializr](https://start.spring.io/). The Maven wrapper scripts retain their Apache Software Foundation license headers. Runtime and test dependencies are declared in `pom.xml` and retain their respective licenses.

The application, dashboard, tests, and project documentation were developed for this independent project with AI assistance. Examples are synthetic. No employer implementation, private repository code, customer data, or credentials were used.

The optional TypeScript MCP companion follows the official SDK's structured-output/stdio APIs. Its dependencies and integrity hashes are pinned in [package-lock.json](../diagnostics/package-lock.json); the MCP SDK, Zod, TypeScript and Node type definitions retain their own licenses. Dependencies are installed from npm rather than copied into this repository.

The [MIT license](../LICENSE) covers this project's original source and documentation; it does not replace third-party licenses. The design references in the [project brief](project-brief.md) explain the failure mode and existing alternatives.
